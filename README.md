# Agolic site

The page at <https://agolic.aprover.ai>, served by GitHub Pages from `main`.

`CNAME` holds the address. The page is `index.html`, with no build step; `rubbing-hero/` holds the crayon rubbing behind its first screen (style, script and two stills for browsers without scripts). `python tests/run.py` checks it, and `tests/README.md` says what it guards.

The code is under Apache-2.0 (`LICENSE`). The fonts are under the SIL Open Font License (`fonts/`).
